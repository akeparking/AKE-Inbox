# AKE Inbox v0.4.2：保留多租户功能的审查修复版

本版基于 v0.4.0，合入 v0.3.1 的五项审查修复。保留组织隔离、客户与联系人、独立项目、任务、报价版本、成交与重开、营销报表、AI 建议、会话接待及桌面 CRM 路由。没有用旧版文件覆盖这些新功能。

新增 19 项回归：14 项来自五项修复，5 项覆盖 SaaS 回执与并发边界。真实隔离 PostgreSQL 使用独立数据库和受限 SaaS 运行角色；外部网络调用使用桩，不发送真实业务数据。

本版执行 Ponytail Audit + Codex 原生分析，再运行 Semgrep CE 1.182.0 和 Gitleaks 8.30.1 一次性扫描。准确提交、实际测试数量、CI 结果、规则哈希、排除项和扫描命中复核以 Release 附件 `verification.json`、`audit-summary.zh-CN.md`、`security-scan.sanitized.json` 为准。工具不常驻，不新增扫描 CI。

## 升级与数据保留

从 v0.4.0 升级没有新增 SQL，已有迁移保留至 `010_saas_crm.sql`。较早版本应按既有部署手册升级；不能跳过租户配置、受限数据库角色和行级权限设置。

更新前保存配置、数据库备份和原运行目录，等待旧进程的在途发送完成，然后一起更新 Core API 与 worker。只替换 Windows ZIP 不会应用服务端修复。保留所有旧回执与发送意图；旧 Meta Live 任务必须人工核对，不删除尝试记录，不自动迁移或重放。

Windows 继续使用协议 2，保留用户数据和渠道绑定。回退必须保留新增 CRM 数据和审计记录，不能用旧数据库覆盖现有业务。

## 本次边界

本次发布不部署办公室或 VPS 服务，不启用真实 Meta/Google 回传，不连接或重绑渠道。真实 Windows 实机、8 小时观察、真实渠道/CRM/广告平台受理与匹配均未在本轮执行；历史验收不计为本轮通过。增量发布政策见 [VERSIONING.md](VERSIONING.md)。
