# AKE Inbox v0.3.0 — 接待与 Meta 回传预发布版

服务端新增深色导航、蓝色选中态、会话旁的客户／询盘信息，以及网站与原生表单分开的人工 Meta 回传流程。窗口客户端继续使用协议 2；旧版客户端可以打开升级后的接待页。

- 本版 Windows 包由 v0.3.0 源码构建；内置入口与登录、托盘、接待租约保持既有行为。
- 服务端需要执行新增的幂等数据库迁移，再更新 Core 和原生接待扩展；无需重绑渠道、重置用户或覆盖数据库。
- 发布部署为 Mock；Meta Test Events 与 Live 均未启用。API 受理、后续处理、匹配状态分别记录。
- Windows 实机通知、资源测量及 8 小时观察未在本版执行，因此标为预发布。不要将历史版本验收作为本版结果。

完整源码、部署说明和验证范围见 [整体源码报告](../RELEASE_REPORT_v0.3.0.md)。
