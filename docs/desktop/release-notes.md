# AKE Inbox v0.2.1

Windows 接待员现在可以下载完整 ZIP、解压、打开 `AKE-Inbox.exe` 并登录。公司入口已预置，个人电脑无需安装业务后台或配置模型 Key。

- 登录且连接成功后自动接待；最小化、托盘和锁屏继续在线。每个实例独立续约，同账号保持一个席位，退出一台不会误下线另一台。
- 自己的新客户消息触发任务栏闪动、数字角标和隐私通知；点击通知打开会话，未读数与服务端同步。声音及开机启动默认关闭。
- 修复托盘通知恢复窗口后会话区域空白：最小化时保留页面尺寸，恢复时重新布局。
- 托盘、最小化、锁屏和其他页面不会把当前会话的新消息自动标为已读；真正查看后再同步。重复点击当前会话不再整页刷新。
- 增加暂停接待、连接状态、手动重连、通知设置及 GitHub 更新检查。初次同步不轰炸历史通知，重连后合并新未读提醒。
- 客户与知识页面按需加载，磁盘缓存限制为 64 MiB。设置和有效登录留在 Windows 用户目录，ZIP 升级不覆盖它们。
- 办公室主机继续负责数据库、渠道连接、轮询和 AI；公司 API Key 留在主机。VPS 保持 HTTPS / WebSocket 中转。后台兼容旧客户端，不迁移数据库、不清空渠道绑定，保留退信循环防护。
- 修复客户重新打开已解决会话后 AI 未恢复、基础项目信息咨询被误拦截的问题；显式暂停、知识依据和商务承诺边界继续生效。API 自动回复在客户页面显示为 AI Agent。
- 模型适配器增加可选的 Anthropic Messages 协议和关闭推理配置，兼容公司网关；原 OpenAI 接口默认行为保留，截断或无效输出仍拒绝发送。

附件包括 Windows x64 ZIP、源码 ZIP/TAR.GZ、可离线打开的 `index.html`、`client-compatibility.json` 和 `SHA256SUMS.txt`。完整实机验证范围、资源实测和待验证项目见 HTML。发布前保留草稿，验收未完成不标记正式发布。

2026-10-27 的同机 15 分钟托盘实测：新版平均 CPU 0.032%，总进程平均 RSS 616.5 MiB；此前候选版为 566.8 MiB。用户已选择保留功能并接受增加 49.7 MiB，最初“不高于旧版”的内存目标没有达到。通知中心点击后的会话内容和回复框已经人工确认。

此版未签名，采用提示更新后手动下载 ZIP；退出旧版并解压新版到新目录即可升级。办公室主机断电、睡眠或断网时接待暂停，VPS 没有离线消息缓冲。完整开机恢复、多台实体电脑和各渠道重新绑定后的真实收发须单独验收。
