# AKE Inbox v0.4.0 — Inbox＋CRM 多租户正式版

在已上线 v0.3.0 上加入组织隔离、客户与商机、跟进、报价版本、成交归因和签名收件入口。新工作台为 `/sales/saas`，也可从原生接待导航进入。

- 本版 Windows 包由 v0.4.0 源码构建，继续使用协议 2；登录、托盘、租约与既有用户数据保持兼容。
- 先升级服务端、迁移和接待扩展，再打开新入口；只更换 Windows ZIP 不会部署 CRM。
- 生产广告保持 Mock，真实平台授权、受理与匹配另行验收。
- 沿用项目已经接受的桌面基础流程；本次重新执行桌面逻辑回归，新 Windows 实机与 8 小时观察没有重跑，不标记为本版通过。

完整源码与部署验证见 [版本报告](../RELEASE_REPORT_v0.4.0.md)和 Release 附件 `verification.json`。
